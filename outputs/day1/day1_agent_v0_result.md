## 8. 추가 확인 필요 사항
- **연관 알람 동시 발생 분석**: `ALM-TEMP-402` 발생 시점 주변에서 `ALM-FLOW-301` 또는 다른 진공/가스 관련 알람이 함께 기록되었는지 **추가 로그 분석이 필요**합니다.
- **챔버별 세부 데이터**: 동일 설비 내 여러 챔버가 있다면, **어느 챔버에서 집중 발생했는지** 챔버 ID별 발생 빈도를 확인할 필요가 있습니다.
- **공정 레시피 변동 여부**: 해당 시간대에 **레시피 변경**이 있었는지 공정 관리 기록을 확인할 수 있습니다.
- **온도 측정값 실제 편차 크기**: 알람 발생 시 기록된 **구체적인 온도 값과 기준 범위**를 비교하여 편차 정도를 파악할 필요가 있습니다.

## 10. 2일차 RAG 실습 연결

2일차에는 `alarm_manual.md` 단순 검색을 다음 구조로 확장합니다.

- Markdown 문서 로드
- chunk 분할
- metadata 생성
- Top-3 검색
- 검색 결과를 State에 저장
- 근거 문서 기반 답변 생성

즉, Day1 Agent v0는 2일차 RAG Agent v1로 확장되는 출발점입니다.
